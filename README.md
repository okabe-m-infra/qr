# 仕分けQR表示

写真の自動仕分けソフト（PhotoSorter）で使う「区切りQR」を、スマホに表示するWebアプリです。

- 公開URL: https://okabe-m-infra.github.io/qr/
- ログイン・インストール不要。スマホのブラウザで開き「ホーム画面に追加」するとアプリのように使えます
- 一度開けば電波がない場所でも動きます
- 入力したリストは各スマホの中だけに保存され、サーバーには送信されません

## 更新するとき
`index.html` を差し替えたら、`sw.js` の `VERSION` を上げてください（例：psort-v2 → psort-v3）。
